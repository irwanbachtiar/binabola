Quick Reference Guide

Cara Membuka Aplikasi

1 Cari icon BinaBola di home screen atau app drawer
2 Tap/Klik icon untuk membuka aplikasi
3 Aplikasi terbuka fullscreen seperti native app

Fitur Utama

Akses Cepat

Buka langsung dari home screen tanpa browser

Offline Support

Tetap bisa akses halaman yang sudah di-cache

Auto Update

Update otomatis saat ada versi baru

Data Tersimpan

Login dan cache tersimpan di device

Quick Actions (Long-Press Icon)

Dashboard Absensi Penilaian

Android only - Long-press icon untuk akses cepat

Status Indicator

Mode Aplikasi Running as app
Mode Offline No internet
Install Install app prompt
Update New version available

Troubleshooting

Masalah Solusi
App lambat Check koneksi internet
Clear cache browser
Restart device
Data tidak update Pull to refresh (swipe down)
Check online/offline status
Logout dan login ulang
Icon tidak muncul Check app drawer (Android)
Restart device
Reinstall app

Cara Uninstall

Android

Long-press icon → Uninstall

iOS

Long-press → Remove App

Desktop

chrome://apps → Remove

Keyboard Shortcuts (Desktop)

F5 atau Ctrl + R Refresh page
Ctrl + Shift + R Hard refresh (clear cache)
F12 Open DevTools (debug)
Ctrl + P Print page

Tips & Best Practices

  • Selalu buka app dari home screen, bukan browser
  • Update aplikasi saat ada notifikasi update
  • Pastikan online saat input data absensi/evaluasi
  • Pull to refresh untuk lihat data terbaru
  • Logout jika menggunakan shared device
  • Backup data penting dengan screenshot
